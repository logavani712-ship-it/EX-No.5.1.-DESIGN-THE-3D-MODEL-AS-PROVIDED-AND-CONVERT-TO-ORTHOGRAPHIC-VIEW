# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW

#### Date : 12.11.2026 

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1.Open the CAD software and create a new part file. Select the XY plane and start a sketch for the component’s main base.

2.Draw the outer base shape by following the top view in the drawing, including the rounded ends and mounting lugs.

3.Add the mounting holes at the locations shown in the drawing. Use the dimensions to position the holes accurately.

4.Sketch the central circular portion of the base and make sure it is aligned with the part’s centerline.

5.Finish the sketch and extrude the base to the thickness specified in the drawing.

6.Select the top face of the base and start a new sketch for the raised central boss.

7.Draw the concentric circles for the boss and extrude them to the height shown in the drawing.

8.Create the central bore through the boss using the Hole or Cut feature.

9.Add the counterbore or recessed circular steps around the central bore, following the section views.

10.Create the smaller side holes and other openings at the positions shown in the top view.

11.Use the section views to add the required internal steps, recesses, and changes in thickness.

12.Apply fillets to the rounded edges and chamfers to the edges where shown in the drawing.

13.Compare the model with the top, side, and sectional views to check the shape and feature positions.

14.Confirm that the important dimensions match the drawing and correct any errors.

15.Save the completed CAD model with a suitable file name.
